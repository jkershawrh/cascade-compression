# Support

Cascade Compression is community-supported software.

- Use GitHub Discussions or issues for usage questions and reproducible bug reports.
- Use GitHub private vulnerability reporting for security concerns; see `SECURITY.md`.
- Include the package version, Python version, operating system, and a minimal synthetic reproducer.
- Do not attach production signals, credentials, endpoints, deployment manifests, or customer data.

Only the latest released minor version receives fixes. No commercial support or production service
level agreement is implied by this repository.
