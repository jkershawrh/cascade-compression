# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest `0.1.x` release | Yes |
| Unreleased development snapshots | Best effort |
| Older versions | No |

## Reporting

Report vulnerabilities using GitHub private vulnerability reporting. Do not open a public issue
for suspected credentials, private endpoints, tenant information, or exploitable behavior.

Include affected versions, impact, reproduction steps using synthetic data, and any suggested
mitigation. Maintainers will acknowledge the report through GitHub and coordinate disclosure after
a fix is available. Do not test against systems or data you do not own or have permission to use.

Supported security fixes target the latest released minor version. Never include production data,
credentials, deployment overlays, raw evidence, or customer identifiers in a report fixture.
